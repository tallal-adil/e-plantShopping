# e-PlantShopping

## Paradise Nursery

e-PlantShopping is a React-based online plant shopping application called **Paradise Nursery**.

The application allows users to browse different categories of houseplants, view plant information and prices, and add plants to a shopping cart.

## Project Name

e-PlantShopping

## Application Name

Paradise Nursery

## Description

Paradise Nursery is an online plant shopping application developed using React and Redux Toolkit.

The application provides a user-friendly interface where customers can explore different categories of houseplants, add plants to their shopping cart, manage quantities, remove items, and view the total cost of their purchases.

## Main Features

- Paradise Nursery landing page
- About Us section
- Multiple categories of houseplants
- Plant thumbnails, names, and prices
- Add to Cart functionality
- Shopping cart
- Increase and decrease item quantities
- Remove items from the cart
- Dynamic cart item count
- Total cart amount calculation
- Checkout button
- Continue Shopping functionality

## Technologies Used

- React
- JavaScript
- Redux Toolkit
- React Redux
- Vite
- HTML
